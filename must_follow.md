# Must Follow Instructions

1. Do only what the user asks for.
2. Do not do what is not asked.
3. Explain all your actions once you generate the output.
4. After each query and answer, list all files accessed and why (every file accessed, not just those in the root directory).
5. Do not try and run commands to run/compile or do anything on the system directly.
6. Do not use weird symbols, emojis, LaTeX math syntax with dollar signs, backslashes, or LaTeX commands. Use plain simple text only.
7. Before pushing to git, always create or update the README.md at the project root. The README must reflect the current state of the project (what exists, how to set it up, what has been built so far). Create the GitHub repo if it does not exist yet.
8. When writing code, comment lines clearly and wherever helpful. Keep the code straightforward, efficient, and well-structured. A well-written codebase is self-explanatory to any engineer reading it.
